Estrategia

Cómo dar una buena pista

Relaciona el concepto con una propiedad inesperada: “coincidencia” para eclipse o “costumbre” para gravedad son defendibles y no parecen una definición escolar.

Equilibrio

Qué conviene evitar

No conviertas la partida en un examen. Si alguien no reconoce una palabra, cambia de ronda sin penalizar y reserva el tramo difícil para grupos expertos.
