Estrategia

Cómo dar una buena pista

Una cifra, gesto o idea táctica funciona mejor que el escudo: “doce” para Boca, “304” para Lamine Yamal y “vacío” para falso nueve abren discusión.

Equilibrio

Qué conviene evitar

No uses colores de camiseta, ciudad o rival directo en la primera ronda. Mezcla conceptos tácticos solo si todos siguen fútbol con cierta frecuencia.
