Estrategia

Cómo dar una buena pista

Una serie, evento o muletilla suele funcionar mejor que el país o la plataforma. “Velada” para Ibai y “Troncos” para Perxitaa dejan margen al farol.

Equilibrio

Qué conviene evitar

No uses el nombre real, la primera letra o una pareja pública. Esta categoría solo es justa si el grupo sigue a creadores parecidos.
