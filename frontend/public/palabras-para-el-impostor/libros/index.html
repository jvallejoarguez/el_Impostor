Estrategia

Cómo dar una buena pista

Elige un motivo secundario: “capítulos” para Rayuela, “sótano” para El Aleph o “cuaderno” para La casa de los espíritus son sutiles pero justificables.

Equilibrio

Qué conviene evitar

No cites un personaje del título ni la adaptación más conocida. Confirma que las obras difíciles forman parte de las lecturas compartidas.
