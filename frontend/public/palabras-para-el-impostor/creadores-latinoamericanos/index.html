Estrategia

Cómo dar una buena pista

Usa equipos, comunidades o formatos: “Pío” para Rivers, “Army” para Coscu y “Arroyito” para JuanSGuarnizo son pistas para fans, no descripciones genéricas.

Equilibrio

Qué conviene evitar

No uses la nacionalidad como única pista y no mezcles nombres que el grupo nunca haya visto. Lo divertido es reconocer referencias, no adivinar por descarte geográfico.
