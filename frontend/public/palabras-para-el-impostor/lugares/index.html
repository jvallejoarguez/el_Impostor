Estrategia

Cómo dar una buena pista

Describe una experiencia secundaria. “Despedida” para aeropuerto es más sutil que “avión”, y “coro” para estadio demuestra contexto sin nombrar el deporte.

Equilibrio

Qué conviene evitar

Evita el objeto más obvio del lugar —libros, médicos, cuadros— durante la primera vuelta. Guarda la pista directa para defenderte si te acusan.
