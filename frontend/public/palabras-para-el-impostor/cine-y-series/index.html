Estrategia

Cómo dar una buena pista

Busca una escena, objeto o regla interna: “escalera” para Parásitos, “chasquido” para Avengers o “treinta y tres” para Dark recompensan a quien conoce la obra.

Equilibrio

Qué conviene evitar

No digas un actor, personaje principal o parte del título. Separa cine de culto si el grupo prefiere referencias masivas.
