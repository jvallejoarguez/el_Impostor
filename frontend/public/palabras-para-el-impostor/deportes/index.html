Estrategia

Cómo dar una buena pista

Piensa en una regla o un momento: “silencio” para tenis, “esquina” para boxeo o “tercer tiempo” para rugby separan a quien conoce el deporte de quien improvisa.

Equilibrio

Qué conviene evitar

No menciones pelota, red o pista si es la asociación inmediata. Asegúrate de que las disciplinas difíciles sean conocidas por todo el grupo.
