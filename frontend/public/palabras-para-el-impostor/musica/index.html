Estrategia

Cómo dar una buena pista

Usa una etapa o un detalle: “Eras” para Taylor Swift, “sobremesa” para C. Tangana o “pedales” para shoegaze son reconocibles sin tararear la respuesta.

Equilibrio

Qué conviene evitar

No cantes una melodía ni digas parte de una letra. En artistas, evita el país o una colaboración que revele demasiado.
