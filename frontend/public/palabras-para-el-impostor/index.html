Palabras para El Impostor

Una buena palabra debe ser conocida por el grupo, pero permitir pistas ambiguas. Si es demasiado fácil, el impostor cae rápido; si es demasiado rara, todos parecen sospechosos.

Fáciles

Animales, comida, lugares y objetos cotidianos. Van bien para grupos nuevos o partidas rápidas.

Medias

Cultura, profesiones, deportes y naturaleza. Permiten pistas más creativas sin romper la partida.

Caóticas

Videojuegos, streamers, youtubers, libros y ficción. Perfectas para grupos que comparten referencias.

Cómo elegir buenas palabras

  1. Elige temas que todos conozcan mínimamente.
  2. Evita palabras demasiado específicas si hay jugadores nuevos.
  3. Mezcla categorías para que el impostor no pueda adivinar solo por contexto.
  4. Usa pistas con doble sentido para que el debate sea más divertido.
